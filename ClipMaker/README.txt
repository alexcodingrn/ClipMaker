CLIPMAKER - stream clips -> TikTok / Reels / Shorts
====================================================
Turns your Twitch clips into vertical videos: webcam on top, gameplay below,
subtitles written for you, sound effects, GIFs and stickers. Runs on your own
Windows PC. Free.


START IT (nothing to install)
-----------------------------
1. Right-click the zip > Extract All > open the new ClipMaker folder.
2. Double-click start.bat. If Windows says "Windows protected your PC",
   click More info > Run anyway.
3. The first time it downloads what it needs (5-10 minutes). Leave it alone.
4. ClipMaker opens in its own window. Keep the black window open (you can
   minimize it). Closing it turns ClipMaker off.
Tip: ClipMaker puts a ClipMaker icon on your Desktop. Right-click it > Pin to taskbar.


SETUP (about 3 minutes, ClipMaker walks you through it)
-------------------------------------------------------
The first time it opens, a setup guide pops up. You can open it again any
time with the "Setup" button at the top. Or click "Ask AI" and ask
"how do I set up Twitch?".

1. Twitch: press "Log in with Twitch". A Twitch page opens in your browser.
   Check the code matches, press Activate, then Authorize. That's it.
2. GIFs & stickers (optional): make a free key at developers.giphy.com
   (Create an API Key > API > name it ClipMaker), paste it, press Save & test.
3. AI helper (optional): press Set up the AI. One-time ~2 GB download.
4. Press Start watching for my clips.


EVERY STREAM
------------
- Keep your Stream Deck clip button exactly how it is.
- Open ClipMaker before you go live and leave it open.
- After stream your clips show up in Make clips with a purple dot (new clips
  can take a few minutes to show up on Twitch's side).
- First clip only: make sure the pink box is on your webcam. Drag the
  "Webcam" tag to move it, drag a corner to resize. It's remembered.
- Add sounds (a few come with it: vine boom, ayooo...) or GIFs, press
  Make this clip. Then Finished clips > Download.

Ask the AI things like "add the vine boom when I say no way",
"cut this to the best 10 seconds" or "write me a TikTok caption".
